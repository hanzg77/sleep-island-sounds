# 睡眠岛 · 开放声音库

[English](README.md) · [公开录音目录](SOUNDS.md) · [JSON 目录](catalog.json) · [多语言译文](translations/) · [贡献说明](CONTRIBUTING.md)

收集自然与生活中的真实录音，让做游戏、视频、声音工具和其他创作的人，找到来源清楚、授权明确的声音。

实际公开数量以本次快照的 [SOUNDS.md](SOUNDS.md) 为准；空目录表示导出时没有公开作品，不是演示数据。

[访问睡眠岛](https://www.sleepisland.org/?utm_source=github&utm_medium=referral&utm_campaign=open_sound_library)

## 网站、GitHub 与 App

- 网站负责搜索、试听、下载、上传和审核。
- GitHub 提供开放目录、译文、使用说明、纠错与声音需求讨论。
- Cloudflare R2 保存音频与封面；本仓库不复制大体积音频。
- App 服务睡眠与放松，已有 App 内容不会自动变成开放素材。

## 如何使用

从目录进入作品页，先试听，查看实际时长、声音描述、作者和许可。公开作品可免登录下载。使用时保留作品名、作者、来源与许可链接；剪辑、降噪、混音等修改也请说明。

开放作品采用 **CC BY 4.0**，由作者逐条确认授权。请以作品页的实际许可为准。署名示例（请替换占位内容）：

> 《作品名》— 作者，作品来源链接，CC BY 4.0（https://creativecommons.org/licenses/by/4.0/）。修改说明：裁剪并混入游戏场景。

目录是一次公开数据快照，作品之后可能因纠错或撤回而改变可用状态；具体边界见 [授权说明](LICENSE.md)。

## 每日目录与翻译

现有 Codex 定时任务每天北京时间 9 点读取网站公开目录，补齐新作品和原文变化后的其余 14 种语言，再同步到本仓库。`catalog.json` 保留作者原文，`translations/<语言>.json` 保存标题、说明、标签、公开地点与制作说明的译文。空字段保持空，作者姓名、设备、录制日期与音频不翻译。

译文通过原文指纹对应作品；原文没变就复用，已撤回作品退出当前快照。读取或校验失败时保留上次有效文件。在 GitHub 发布译文，不代表官网已经展示；官网接入另行完成。每日翻译不会阻塞原作品公开。

## 一起完善

欢迎通过 Issues 提出想找的声音、资料纠错、翻译与使用案例。不要在公开 Issue 附上未授权音频、私人谈话或个人敏感信息。可在网站[注册并上传录音](https://www.sleepisland.org/library/upload/)；普通投稿按网站规则审核，可信作者在本地工作台处理完成的作品可直接公开。

**ethan** 提供本人原创的实地录音，实际设备与录制日期以每条作品资料为准。尚未发布的原始素材保持私有，待作者确认试听与许可后再进入公开目录；不根据未校准的录音笔时间编造录制日期。
