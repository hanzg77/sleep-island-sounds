# 睡眠岛 · 开放声音库

[English](README.md) · [公开录音目录](SOUNDS.md) · [JSON 目录](catalog.json) · [贡献说明](CONTRIBUTING.md)

收集自然与生活中的真实录音，让做游戏、视频、声音工具和其他创作的人，找到来源清楚、授权明确的声音。

**当前状态：首批经过审核的作品正在准备。** 实际公开数量以 [SOUNDS.md](SOUNDS.md) 为准；空目录表示尚无正式发布的音频，不是演示数据。

[访问睡眠岛](https://www.sleepisland.org/?utm_source=github&utm_medium=referral&utm_campaign=open_sound_library)

## 网站、GitHub 与 App

- 网站负责搜索、试听、下载、上传和审核。
- GitHub 提供开放目录、使用说明、纠错与声音需求讨论。
- Cloudflare R2 保存音频与封面；本仓库不复制大体积音频。
- App 服务睡眠与放松，已有 App 内容不会自动变成开放素材。

## 如何使用

从目录进入作品页，先试听，查看实际时长、声音描述、作者和许可。公开作品可免登录下载。使用时保留作品名、作者、来源与许可链接；剪辑、降噪、混音等修改也请说明。

新开放投稿采用 **CC BY 4.0**，由上传者逐条确认授权，审核后公开。请以作品页的实际许可为准。署名示例（请替换占位内容）：

> 《作品名》— 作者，作品来源链接，CC BY 4.0（https://creativecommons.org/licenses/by/4.0/）。修改说明：裁剪并混入游戏场景。

目录是一次公开数据快照，作品之后可能因纠错或撤回而改变可用状态；具体边界见 [授权说明](LICENSE.md)。

## 一起完善

欢迎通过 Issues 提出想找的声音、资料纠错、翻译与使用案例。不要在公开 Issue 附上未授权音频、私人谈话或个人敏感信息。音频投稿统一走网站上传和审核流程，开放注册后可参与。

首批原创录音由 **ethan** 使用 **Zoom H2e** 录制。尚未发布的原始素材保持私有，待作者确认试听与许可后再进入公开目录；不根据未校准的录音笔时间编造录制日期。
