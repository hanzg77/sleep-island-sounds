# License scope / 授权范围

Each published recording has its own license field and source page. Only an entry explicitly marked `CC-BY-4.0` is offered under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/). Read the [full license](https://creativecommons.org/licenses/by/4.0/legalcode) for its terms.

Preserve creator credit, the source and license links, and an indication of changes. A CC license does not automatically clear privacy, publicity or trademark rights. Removal from the website does not revoke rights already granted to compliant users.

The license recorded for an entry covers the material explicitly offered on its source page. It does not license private drafts, unreleased recordings, existing Sleep Island app content, logos, trademarks or the website/app source code. This catalog does not set a software license for those projects.

每条公开录音以作品页和目录中明确标注的许可为准。空目录不代表素材库已整体授权；草稿、旧 App 内容、商标和网站/App 源码均不因建立此仓库而获得开放许可。

For a rights concern, contact contact@sleepisland.org with the public work URL. Avoid posting confidential evidence in a public issue.
